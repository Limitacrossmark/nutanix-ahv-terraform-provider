|-----------|---------------------|-----------|

| **5. Apply** | Provision resources | ~10 min |
| **6. Destroy** | Safe teardown | ~5 min |

> **💡 Tip:** Always run `terraform plan` before `apply` — a misconfigured provider can target the wrong cluster.
